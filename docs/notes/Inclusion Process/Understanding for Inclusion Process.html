What is Inclusion Process?

Condensation, Metastability, and Movement of the Condensate

Probability
Interacting Particle Systems
Metastability
Author

Sungjun Park

Published

1 Introduction

Inclusion process는 여러 입자가 유한한 상태공간 \(S\) 위에서 움직이는 interacting particle system이다.

이 모델의 특징은 입자들이 서로 밀어내는 것이 아니라, 이미 입자가 많이 모여 있는 곳으로 더 잘 이동한다는 점이다.

이러한 attractive interaction 때문에 많은 수의 입자가 한 지점에 몰리는 현상이 발생할 수 있고 이를 condensation이라고 한다.

이 글에서는 inclusion process의 기본 정의, condensation의 의미, 그리고 condensate의 metastable behavior가 무엇을 뜻하는지를 알아보고자 한다.

2 Underlying Random walk

Inclusion Process는 입자들이 상호작용하면서 움직이는 입자계이다. 이때, 입자들이 어떤 공간 위에서 어떤 방향과 rate로 이동할 수 있는지를 먼저 정해야 한다. 이를 위해 finite state set \(S\) 위에서의 underlying random walk를 정의하자.

\[S = \{ x_1, x_2, \ldots , \kappa \}\]

를 잡자. 이때, \(x \in S\)는 입자가 위치할 수 있는 site이다.

Definition 1 (Underlying random walk) \(S\) 위에서 jump rate \(r(\cdot, \cdot):S \times S \to [0,\infty)\)를 가지고 continuous time, irreducible 한 Markov chain \((X(t))_{t \in [0,\infty)}\)를 underlying random walk로 잡는다.

이때, \(m(\cdot)\)은 Markov chain \(X(\cdot)\)의 invariant measure라 하고, 서술의 편의를 위해 \(r(x,x)=0\) for all \(x \in S\)라 하자.

전체 입자의 수를 \(N\)이라 하면, configuration space는

\[\mathcal{E}_N\]

[ E_N = ]

로 정의된다.

여기서

[ _x ]

는 site (x)에 존재하는 입자의 수를 의미한다.

즉, 하나의 configuration

[ = (*x)*{x S} ]

는 전체 (N)개의 입자가 각 site에 어떻게 분포되어 있는지를 나타낸다.

3 3. Inclusion Process의 Generator

Inclusion process는 (E_N) 위의 continuous-time Markov chain으로 정의된다.
일반적으로 generator는 다음 형태를 가진다.

[ (L_N F)() = _{x,y S} _x (d_N + _y) r(x,y) . ]

여기서 각 기호의 의미는 다음과 같다.

  • (r(x,y)): underlying random walk가 (x)에서 (y)로 이동하는 rate
  • (d_N > 0): diffusion strength를 조절하는 작은 parameter
  • (^{x,y}): configuration ()에서 입자 하나를 (x)에서 (y)로 옮긴 configuration
  • (F : E_N ): test function

즉, (_x)개의 입자 중 하나가 (x)에서 (y)로 이동하는 rate는

[ _x(d_N + _y) r(x,y) ]

이다.

4 4. 왜 “Inclusion”인가?

이 rate를 다음과 같이 나누어 볼 수 있다.

[ _x(d_N + _y)r(x,y) = d_N _x r(x,y) + _x _y r(x,y). ]

첫 번째 항

[ d_N _x r(x,y) ]

은 입자들이 underlying random walk에 따라 움직이는 diffusive part로 볼 수 있다.

반면 두 번째 항

[ _x _y r(x,y) ]

은 site (y)에 이미 입자가 많을수록 (x)의 입자가 (y)로 더 잘 이동한다는 것을 의미한다.

따라서 입자들은 서로를 끌어당기는 것처럼 행동한다.
이것이 inclusion process의 핵심적인 attractive mechanism이다.

5 5. Condensation 현상

Inclusion process에서 (d_N)이 충분히 작으면, diffusive effect보다 attractive interaction이 지배적이 된다.

그 결과 대부분의 입자가 하나의 site에 몰리는 현상이 나타날 수 있다.
이를 condensation이라고 한다.

예를 들어 site (x S)에 모든 입자가 모인 configuration을

[ _N^x ]

라고 쓰자. 즉,

[ (_N^x)_z =

\[\begin{cases} N, & z=x, \\ 0, & z \neq x. \end{cases}\]

]

이때

[ E_N^x = {_N^x} ]

는 (x)에 condensate가 위치한 metastable state로 볼 수 있다.

Condensation이 일어난다는 것은 대략적으로 invariant measure (_N) 아래에서

[ *N* ( E_N^x ) ]

이 성립한다는 뜻이다. 여기서 (S_*)는 condensate가 나타날 수 있는 site들의 집합이다.

6 6. Metastability와 Condensate의 움직임

Condensation이 발생하면, process는 대부분의 시간 동안 어떤 (E_N^x) 근처에 머문다.
하지만 매우 긴 시간 scale에서 보면 condensate가 한 site에서 다른 site로 이동한다.

즉,

[ _N^x _N^y ]

와 같은 전이가 드물게 발생한다.

이러한 드문 전이를 관찰하기 위해 적절한 time scale (*N)을 도입한다.
그러면 condensate의 위치 process는 유한 상태공간 (S**) 위의 Markov chain으로 수렴할 수 있다.

이것이 inclusion process에서의 metastable behavior이다.

7 7. Reversible Case와 Non-reversible Case의 차이

Reversible inclusion process에서는 invariant measure가 explicit하게 주어지는 경우가 많기 때문에, condensation과 metastable transition을 potential theory를 통해 분석할 수 있다.

하지만 non-reversible case에서는 일반적으로 invariant measure의 closed-form expression이 없다.

이 때문에 다음 두 문제가 어려워진다.

  1. condensation이 실제로 발생하는지 보이기 어렵다.
  2. metastable transition rate를 계산하기 어렵다.

그럼에도 non-reversible inclusion process에서는 reversible case와 다른 흥미로운 현상이 나타난다.
특히 condensate의 이동 time scale과 limiting dynamics가 달라질 수 있다.

8 8. Zero-range Process와의 비교

Zero-range process와 inclusion process는 둘 다 condensation을 보이는 대표적인 interacting particle system이다.

하지만 condensate가 이동하는 방식은 다르다.

Zero-range process에서는 일부 입자가 먼저 떨어져 나와 다른 곳에 작은 condensate를 만들고, 이후 전체 condensate가 이동하는 식의 long-range movement가 가능하다.

반면 inclusion process에서는 condensate가 보통 이웃 site들을 따라 순차적으로 이동하는 구조가 나타난다.

이 차이는 두 모델의 generator가 가진 interaction mechanism의 차이에서 비롯된다.

9 9. 요약

Inclusion process는 다음과 같이 요약할 수 있다.

  1. 유한한 상태공간 (S) 위의 interacting particle system이다.
  2. 입자는 (x)에서 (y)로 rate (_x(d_N+_y)r(x,y))로 이동한다.
  3. (_y)가 클수록 (y)로 이동할 rate가 커지므로 attractive interaction이 존재한다.
  4. (d_N)이 작으면 대부분의 입자가 하나의 site에 몰리는 condensation이 발생할 수 있다.
  5. 긴 시간 scale에서 condensate의 위치가 site들 사이를 이동하며, 이것이 metastability 문제로 해석된다.
  6. non-reversible case에서는 invariant measure를 알기 어렵기 때문에 분석이 훨씬 섬세해진다.
